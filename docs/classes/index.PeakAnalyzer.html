    Class PeakAnalyzer

    A specialized class for decoding audio data and generating waveform peaks.

    It leverages the Web Audio API (AudioContext) to process audio buffers and extract amplitude data for visualization.

    generatePeaks

    • generatePeaks(media: string | Blob, samples?: number): Promise<number[]>

      Processes media (URL or Blob) and generates a set of normalized peaks.

      Parameters

      • media: string | Blob

        The URL string or Blob object to analyze.

      • samples: number = 512

        The number of peaks (bars) to generate. Defaults to 512.

      Returns Promise<number[]>

      A promise resolving to an array of normalized peak values (0 to 1).

      Example

      const analyzer = new PeakAnalyzer();

      // Analyze from URL
      const peaksFromUrl = await analyzer.generatePeaks('https://example.com/audio.mp3');

      // Analyze from Blob
      const peaksFromBlob = await analyzer.generatePeaks(myAudioBlob);
