    Function useWaveframe

    • useWaveframe(
          media: string | Blob | undefined,
          options?: UseWaveframeOptions,
      ): { controller: WaveframeController; state: EngineState }

      A headless hook that manages the lifecycle of a WaveframeController.

      It returns a stable controller instance that can be passed to components like or used for custom playback logic.

      Parameters

      • media: string | Blob | undefined

        The audio source (URL string or Blob/File object).

      • options: UseWaveframeOptions = {}

        Additional configuration and an optional external controller.

      Returns { controller: WaveframeController; state: EngineState }

      • controller: WaveframeController

        The stable WaveframeController instance

      • state: EngineState

        The reactive engine state

      Example

      const { controller, state } = useWaveframe('https://example.com/audio.mp3');

      return (
        <div>
          <Waveform controller={controller} />
          <button onClick={() => controller.togglePlay()}>
            {state.isPlaying ? 'Pause' : 'Play'}
          </button>
        </div>
      );
